The Self-Charging Solar Torch — a catalogue photograph of an impossible gadget. A chunky gunmetal flashlight, switched ON, shines its beam onto a solar panel on a small stand, with a cable looping from the panel back into the flashlight: the torch charges itself from its own light. Pure Python (standard library only), no network, deterministic — it draws the whole studio product shot pixel by pixel and writes a 1024×1024 PNG.

## Run it

```sh
python3 main.py
```
